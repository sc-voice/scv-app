# MerkleJson: Swift Implementation

## Overview

MerkleJson is a deterministic MD5 hash generator for JSON structures, ensuring byte-for-byte compatibility with the existing JavaScript implementation. It computes consistent hashes for JSON objects and arrays, making it suitable for:

- S3 audio file key generation
- Content-based addressable storage
- Deterministic caching of segments
- Ensuring consistency across JavaScript and Swift implementations

## Migration from JavaScript

The JavaScript implementation (`/Users/visakha/dev/merkle-json`) was migrated to Swift to:

1. **Ensure consistency**: Audio files on S3 are keyed by MD5 hashes generated by JavaScript merkle-json. Swift code must generate identical hashes or audio lookup fails.
2. **Eliminate external dependencies**: Remove JavaScript runtime dependency from Swift applications.
3. **Type safety**: Leverage Swift's type system for safer hash computation.

### Core Algorithm

The implementation includes an embedded MD5 algorithm (based on http://www.myersdaily.org/joseph/javascript/md5.js) that:

- Processes strings byte-by-byte (UTF-8 encoding)
- Returns 32-character hex strings (lowercase a-f)
- Handles all standard MD5 test vectors correctly

**Known MD5 test values:**
- Empty string: `d41d8cd98f00b204e9800998ecf8427e`
- `'hello\n'`: `b1946ac92492d2347c6235b4d2611184`
- `' '` (space): `7215ee9c7d9dc229d2921a40e899ec5f`
- `'HTML'`: `4c4ad5fca2e7a3f74dbb1ced00381aa4`

### Type Support

MerkleJson handles all JSON-serializable types:

| Type | Behavior |
|------|----------|
| **String** | Hashed directly via MD5 |
| **Number** (Int, Double) | Converted to string, then hashed |
| **Date** | Converted to ISO8601 via `toJSON()`, then hashed |
| **Boolean** | Converted to "true"/"false", then hashed |
| **null** | Converted to "null", then hashed |
| **Array** | Merkle hashing: `hash([a,b]) = hash(hash(a) + hash(b))` |
| **Dictionary** | Keys sorted, canonical format: `"key:hash(value),"` |
| **Optional** | nil values treated as null |

### Canonical JSON Format

Objects are serialized in canonical form for deterministic hashing:

1. **Sorted keys**: Dictionary keys are sorted alphabetically before processing
2. **No whitespace**: Canonical format contains no spaces or newlines
3. **Format**: `{key1:hash1,key2:hash2,}`

**Example**:
```swift
let obj1 = ["b": 2, "a": 1]
let obj2 = ["a": 1, "b": 2]
mj.hash(obj1) == mj.hash(obj2)  // true - keys are sorted
```

### merkleHash Field Caching

Objects can include a `merkleHash` field for performance optimization:

```swift
let mj = MerkleJson()

// If merkleHash is present and cached=true, return it
let obj = ["data": "value", "merkleHash": "abc123"]
mj.hash(obj, cached: true)   // Returns "abc123" without computing
mj.hash(obj, cached: false)  // Computes hash, ignores cached field
```

## Usage

### Basic Hashing

```swift
import scvCore

let mj = MerkleJson()

// Strings
let hash1 = mj.hash("hello")
let hash2 = mj.hash("world")

// Numbers (converted to strings internally)
let hash3 = mj.hash(123)
let hash4 = mj.hash(123.456)

// Arrays (merkle hashing)
let hash5 = mj.hash([1, 2, 3])
let hash6 = mj.hash(mj.hash(1) + mj.hash(2) + mj.hash(3))
// hash5 == hash6

// Objects (canonical sorting)
let hash7 = mj.hash(["b": 2, "a": 1])
let hash8 = mj.hash(["a": 1, "b": 2])
// hash7 == hash8
```

### Custom Hash Tag

```swift
let mj = MerkleJson(hashTag: "customHash")

let obj = ["data": "value", "customHash": "xyz789"]
mj.hash(obj, cached: true)   // Returns "xyz789"
```

### Date Handling

```swift
let date = Date(timeIntervalSince1970: 1518604800)  // 2018-02-14T00:00:00Z
let mj = MerkleJson()

let hash1 = mj.hash(date)
let hash2 = mj.hash(date.toJSON())
// hash1 == hash2
```

## Implementation Notes

### Swift-Specific Considerations

1. **Bool Type Ordering**: Bool must be checked before NSNumber because Bool bridges to NSNumber in Swift. Checking NSNumber first would incorrectly coerce booleans to numbers.

2. **UTF-8 Encoding**: Strings are converted to UTF-8 bytes for MD5 computation, matching JavaScript's `charCodeAt()` behavior.

3. **Date Serialization**: `Date.toJSON()` extension provides ISO8601 format matching JavaScript's `Date.prototype.toJSON()`.

### Performance

- MD5 computation: ~1-2ms for typical document segments
- Merkle hashing adds minimal overhead (concatenation + single hash)
- Caching via `merkleHash` field can skip recomputation if present

## Limitations

1. **Functions not supported**: Swift has no equivalent to JavaScript functions, so function hashing is not implemented. (Functions are not part of typical JSON data structures anyway.)

2. **MD5 only**: CryptoKit doesn't provide MD5 (deprecated), so embedded implementation is used.

3. **Byte-order specific**: Hashes are computed assuming little-endian byte order (standard on modern systems).
