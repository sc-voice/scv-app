## English

### Getting Help

If you encounter issues or have questions about scVoice, please reach out using one of these methods:

### GitHub Issues

For bugs, feature requests, or technical issues:

1. Visit the [scVoice GitHub repository](https://github.com/sc-voice/scv-app)
2. Click the **Issues** tab
3. Click **New Issue**
4. Describe your problem or request in detail:
   - What you were trying to do
   - What happened
   - What you expected to happen
   - Your device and iOS version

### SuttaCentral Discuss & Discover

For general questions, discussions, or feature ideas:

1. Visit [SuttaCentral Discuss & Discover](https://discourse.suttacentral.net/)
2. Navigate to the appropriate category
3. Start a new topic with a clear title and description
4. Our community members and maintainers will help you

### Reporting Security Issues

If you discover a security vulnerability, please do **not** open a public GitHub issue. Instead, email sc.voice.friends@gmail.com with details of the vulnerability.
